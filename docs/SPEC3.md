# 第三轮：剑的多样性扩充（新家族 + 材质品相 + 光环特效）

用户反馈：「剑的模样可不可以多做一些，这个游戏的乐趣之一是剑的多样性」「剑不够炫酷」。
目标：在原作 78 个形态之外，新增 **40 个形态**（共 118），并给每把剑加上随机 **材质品相**（8 种）与高等级 **光环特效**。

坐标/尺寸/材质约定与 docs/SPEC2.md 完全相同（剑尖 +X、正面 +Y、原点护手中心；userData.length/bladeLength/gripLength/width/thickness；metalness ≤ 0.35；不建灯光；单把 < 8k 三角形；`export const FORMS = { [id]: () => Group }` 数字键）。可以使用 src/swords/kit.js 的工具。
**这批是原创形态（原作没有），没有参考图**：请保持与原作一致的低多边形、平直棱面、有限色板的画风，但要更「炫」：多用 emissive 发光部件、悬浮部件、旋转环、粒子状小块（userData.update 驱动动画），越高阶越华丽、越大。每个家族 6 个（隐藏家族）或 11 个（商人线）形态要有清晰的「进化」感：同一主题逐级长出新部件。

## 三、材质品相（负责：swords，在 src/swords.js 核心实现）
导出 `VARIANTS`（数组）与 `setSwordVariant(group, variantId)`：在不改变形态模型的前提下，给剑换「材质」：
| id | 名称 | 效果 |
|---|---|---|
| plain | 原色 | 不变 |
| copper | 赤铜 | 金属部件色相偏向铜红 |
| gold | 鎏金 | 金属部件变金色，微弱金色 emissive |
| frost | 寒铁 | 冰蓝色调 + 青色边缘自发光 |
| obsidian | 黑曜 | 近黑色 + 紫色 emissive 细光 |
| jade | 翡翠 | 翠绿半透明感（略提高 emissive） |
| blood | 血钢 | 暗红 + 红色呼吸光 |
| holy | 圣辉 | 白金 + 柔和金白辉光 |
实现建议：对每个 mesh 的材质（核心已有 clone 机制）按「是否为金属/剑身类颜色」（亮度/饱和度判断，木头握柄、皮革、深色不改）做色相/亮度重映射，并加 emissive。必须与 setSwordHeat / setSwordFrenzy 兼容（heat=0、frenzy=off 时回到「变体后的」外观，而不是原色）。

另外导出 `setSwordAura(group, tier)`：tier 0..3（0=无，1=微光粒子，2=光晕+粒子，3=强光晕+环绕光点+地面光圈），在剑 group 内加一个子对象（标记 userData.noBounds、不参与碎裂、不被 frenzy 替换），由剑的 userData.update 驱动。颜色可从变体/剑的主发光色取。
