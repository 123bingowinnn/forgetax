# 铸剑大师 · FORGETAX 网页版（3D 复刻）

对照 Steam《ForgeTax》官方截图、预告片和玩法视频复刻的网页版：Three.js 第一人称 3D 低多边形地牢工坊。

## 运行
`index.html` 是打包好的单文件版，双击即可游玩（由 `tools/build-single.sh` 生成，改完代码后重新运行）。

开发版入口是 `dev.html`，ES Module 需要通过 HTTP 访问：
- macOS：双击 `start.command`
- 或者：`python3 -m http.server 8765`，然后打开 http://127.0.0.1:8765/dev.html

## 操作
- `WASD` 移动 · 鼠标环顾（点击画面锁定鼠标）· `E` 交互 · `Tab` 查看遗物 · `Esc` 暂停
- 铁砧前：`左键` 敲击 · `右键` 放下剑并离开 · `E` 拿着剑离开 · `1-9` 选消耗品 · `Q` 使用

## 第二轮更新（对照原作数据库 forgetax.tools）
- **新手引导**：第一天由巨龙逐步下指令（拿剑→加热→上砧→敲击→入神→上贡→敲铃→领遗物），场景内金色箭头指示目标，P 跳过。
- **剑的进化树**：78 种形态 1:1 复刻——+0/+2/+4 基础形态；+6/+8 按送货「投放线」分厚铁/怒铁/魔力；+10 起按投放线+隐藏分支进入城塞剑/圣剑/锯刃/龙牙/符文剑/分裂剑六大家族，每 2 级进化到 +20；幽灵商人另售世界树/鱼刃/葬仪剑三条线。进化时有特效提示，C 键打开「剑之图鉴」与成就。
- **遗物**：96 件原作遗物（普通/稀有/传说，按日期解锁进售货机），全部有 3D 模型与效果；19 个成就，其中 16 个解锁传说遗物。
- **幽灵商人**：第 3/6/9… 天来访，出售基础剑、特殊剑线、龙鳞、悔恨发条（R 撤销一锤）、红粉笔、火药包、冷星碎片、遗忘之香、幽灵送货单，同货重复购买 ×3 价。
- **数值**：1000 张签牌堆与破碎曲线、贡额日历（1,800 → 232,000 G）、贡品全额返还金币、第一天三选一免费遗物等均按原作整理。


## 手机 / 平板
自动识别触屏设备，切换为触屏操作：
- 左半屏按住拖动 = 虚拟摇杆移动；右半屏拖动 = 转视角
- **点一下物体**即可交互（拿剑、加热、上贡、投剑、购买、敲铃），或对准后点右下角「交互」
- 铁砧前点屏幕任意处敲击，另有「拿剑离开 / 放下离开 / 道具 / 撤销」按钮
- 右上角「遗物」「图鉴」「☰」菜单（画质：流畅/均衡/精美、全屏、音效）
- 横竖屏都能玩（推荐横屏），适配刘海屏安全区；竖屏时锻造面板会显示在屏幕上方
- 按设备性能自动选择画质，帧率过低时自动降档
调试：地址后加 `#touch=1` 可在电脑上强制触屏模式；`tools/devices.html?shot=anvil&d=390x844,844x390` 多尺寸预览。

## 流程
东墙剑架拿剑 → 西墙熔炉烧红 → 铁砧锻造（破坏 / 损伤 / 维持 / 成功 / 大成功，充能 10 次触发入神）→
北墙贡台献剑 → 按铃 → 铁栏后的巨龙检查贡品。售货机投剑换遗物，幽灵商人第二轮起出现，用金币买东西。
每天傍晚敲铃进贡（4月15日至5月5日），欠贡 3 次游戏结束；之后可继续延长日。
